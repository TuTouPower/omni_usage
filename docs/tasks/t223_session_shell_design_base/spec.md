# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

用户要求把会话面板对齐 `public/frontend_demo/app`（SessionGrid demo）的工作台与会话库，功能+视觉完整对齐。demo 是单壳双页签形态：固定顶栏承载「工作台 / 会话库」页签、主题切换与面板入口。当前会话历史是独立的 6 栏窗口，无外壳概念。本 task 先落地外壳与设计系统基座，为后续槽位模型、面板交互、摘选系统、会话库提供容器与视觉底座。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 会话历史窗口改造为单壳双页签外壳：顶栏含「工作台 / 会话库」居中页签、明/暗主题切换、到「用量面板」「代理面板」的跳转按钮（替代 demo 的两个预留面板入口占位）。
- demo 设计系统落地到会话窗口：语义色 token（canvas/panel/raised/inset、subtle/strong 边框、primary/secondary/muted 文本、lime 强调、danger）、暗色为默认主题、明暗切换并持久化、正文字体与等宽字体按 demo 体系（Noto Sans SC / Space Grotesk / JetBrains Mono 或等价可得字体）、圆角与密度体系。
- 页签切换的状态管理：工作台为默认页签；页签切换不丢失各页内部状态。
- 工作台页签暂挂载现有 6 栏会话视图，保持现有能力（打开会话、勾选复制、实时更新、分页）不回归；会话库页签本 task 只做空态占位。
- 删除 demo 中的拖文件导入与 ⌘K 命令面板入口（不落地、不留占位）。

### 非范围

- 不实现 8 槽位 rail、布局切换、拖拽换位（后续 task）。
- 不实现会话库内容（搜索/筛选/排序/卡片/预览）。
- 不实现摘选托盘与新复制格式。
- 不改消息渲染方式（仍为纯文本）。
- 不动用量面板、代理面板、设置面板、托盘的视觉与结构；设计系统只作用于会话窗口。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] 打开会话窗口，顶栏显示「工作台 / 会话库」两个页签，默认落在工作台；点击页签切换视图，切回后原页内部状态（已打开的会话栏、滚动位置）保留。
- [ ] 顶栏提供明/暗主题切换；切换立即作用于整个会话窗口；重启应用后会话窗口保持上次选择的主题；全新安装默认暗色。
- [ ] 顶栏提供到「用量面板」「代理面板」的跳转按钮，点击分别打开/聚焦对应窗口；原「会话窗口工具栏上的用量/代理面板跳转」入口能力不回归。
- [ ] 会话窗口整体应用 demo 视觉体系：暗色默认、lime 强调色、语义色 token、字体与密度按 demo；窗口内不出现旧主题残留样式。
- [ ] 工作台页签下，现有会话能力不回归：从会话明细表/托盘菜单/最近 6 条打开会话、栏内勾选消息并复制 Markdown、实时推送追加、向上分页、源文件缺失空态。
- [ ] 会话库页签显示空态占位（非报错、非空白）。
- [ ] 窗口内不存在拖文件导入与 ⌘K 命令面板入口。

### 可测试性声明

逐条说明哪些 AC 不可自动测试及原因；全部可测则写「全部 AC 可自动测试」。

- AC 4：视觉整体效果（无旧主题残留）需人工目验；自动测试覆盖主题 token 应用与切换逻辑，目验部分标 `[deploy]` 由黑盒验收兜底。

## 上下文区

reviewer 判测试覆盖时核对本区；实施期可补。

### 有意不测

已判定不写测试的分支与原因。reviewer 不得据此出 blocking finding。无则写「无」。

- 像素级视觉回归：无既有基建设施，靠人工黑盒。

### 测试策略

mock 边界、fixture 来源、断言目标。无特殊约定写「按项目默认」。

- 页签状态、主题切换与持久化、跳转按钮调用的 IPC：renderer 组件/单元测试，mock preload API。
- 现有能力不回归：复用并保留现有 session_history_view 相关测试。

### 未知契约清单

尚未核实的外部 endpoint、API 形态、数据结构、第三方行为须分类标记；核实后删除标记，改为结论并注明验证方式。无则写「无」。

`UNVERIFIED-BLOCKING`：只有用户或外部环境能核实；核实前 `start` 失败。

`UNVERIFIED-SPIKE`：agent 可在执行期 Step 1 实验核实；未核实前不得进入实现。

裸 `UNVERIFIED` 属歧义格式，门禁失败。

- demo 依赖的动效/拖拽/字体等前端库在本项目是否已有等价依赖、新增依赖的体积与许可：`UNVERIFIED-SPIKE`，执行期读 `package.json` 与 demo 的依赖清单核实，新增依赖需报用户确认。

### 风险与回退

- 风险：外壳改造打断现有 history 路由与窗口生命周期（open/focus/messagesUpdated 推送路由）；主题 token 与现有样式冲突导致旧视图破版。
- 回退：单 task 单 commit，直接 revert；现有测试集（session_history_view、route_api、history-window-controller）不回归即视为安全网。

### 依赖与约束

- 会话窗口已有 IPC 通道组与 preload 分权（history/agent 路由全量 API）保持不变；窗口管理沿用现有 window-manager。
- 本 task 是后续工作台/摘选/会话库各 task 的前置（依赖关系见 task.md front matter）。
