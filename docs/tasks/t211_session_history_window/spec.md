# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

需求定稿 `docs/tasks/t211_session_history_window/requirements.md`（决策 3、4、8、9、10、11、12、14、17）。会话历史窗口是本需求的主 UI：单窗口分栏平铺，最多 6 栏，实时刷新，消息可单选 / 多选 / 跨栏复制。本 task 实现 renderer 窗口全部交互。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- route `history` 的窗口视图（`App.tsx` 增加分支），分栏平铺布局：1~2 会话纵向整行，3~6 会话两列网格（3=2+1，4=2×2，5=2+2+1，6=2×3）；每栏内容区独立滚动。
- 栏结构：栏头（agent + 标题 + 关闭 ×）+ 消息列表。顶部工具栏：清空全部按钮（不弹确认）、全局复制按钮（显示总选中数）、会话计数（N/6）、「最近 6 条」按钮。
- 「最近 6 条」按钮：点击后查询最近 6 条会话（按 lastTs/ended_at 降序，复用现有 `getSessions` `{ limit: 6 }`），在窗口内批量打开；超出当前空位时按决策 4 弹模态框由用户腾位。
- 消息渲染（决策 11）：纯文本 + `<pre>` 保留换行缩进，零新依赖。
- 消息选择（决策 8）：hover checkbox 点选，跨栏选择；栏头「已选 N 条 / 全选本栏 / 清除本栏」；选中集按消息 id 跨刷新保留。
- 复制（决策 9）：顶部一次复制所有栏选中，生成 Markdown，按会话分节（`## 会话：标题（agent · 日期）` + `---` 隔离），角色 `**用户**` / `**Agent 名**`，节内按时间升序；从原始消息重新生成，不取 DOM。
- 复制反馈（决策 10）：复制按钮变「已复制 ✓」1.5s 恢复。
- 超 6 处理（决策 4）：打开第 7 个弹模态框，列出当前 6 个会话（agent+标题+打开时间），至少关 1 个新会话才入栏，可取消。
- 空态（决策 12）：源文件不存在的栏显示「该会话的原始记录文件不存在或已删除」，不阻断其他栏。
- 性能（决策 17）：虚拟滚动 + 分页加载（初始最近 200 条，向上加载更早，新增追加尾部）。
- 实时刷新接入：订阅 t210 的推送事件 + 5s 兜底拉取；关闭栏 / 窗口时注销订阅。
- 窗口默认 1400×860（决策 14）。

### 非范围

- 主进程订阅 / watcher 服务与 IPC 实现（t210）。
- 明细表 checkbox 与打开入口（t212）。
- 提取器（t209）。Web 版（决策 16，本期不做）。
- 修改任何会话源文件（硬约束：只读）。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] 窗口按分栏规则渲染 1~6 个会话栏，每栏独立滚动，栏头含 agent、标题、关闭 ×。
- [ ] 顶部工具栏显示清空全部、全局复制（含总选中数）、N/6 计数、「最近 6 条」按钮。
- [ ] 点击「最近 6 条」后，查询最近 6 条会话并在窗口内打开；空位不足时弹模态框按决策 4 腾位。
- [ ] 消息以纯文本 + pre 渲染，user 与 assistant 可区分，时间戳显示到分钟、悬停显示完整时间。
- [ ] 消息可点选，跨栏选中；栏头显示已选数并支持全选本栏 / 清除；刷新后选中保留。
- [ ] 全局复制生成符合格式的 Markdown（多会话分节 + `---` 隔离 + 角色粗体），写入剪贴板。
- [ ] 复制后按钮变「已复制 ✓」1.5s。
- [ ] 已有 6 栏时再打开，弹模态框列出 6 个会话，关闭至少 1 个后新会话入栏；取消则不入栏。
- [ ] 清空全部一键关闭所有栏（不弹确认）。
- [ ] 源文件缺失的栏显示空态文案，其他栏不受影响。
- [ ] 长会话虚拟滚动，初始加载最近 200 条，向上加载更早；新增消息追加尾部不打断当前滚动位置。
- [ ] 订阅推送到达时对应栏追加新消息；5s 兜底拉取生效。
