## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 会话面板（SessionPane）头部元信息：不再显示完整软件名文字（source 字符串），软件识别由已有 icon 徽标承担；目录只显示最后一级目录名；字号层级互换（标题小字号、元信息大字号）；元信息组成为模型、目录、轮次、token、日期，其中日期显示**最后一条消息的精确时间**（含年-月-日 时:分:秒）。
- 侧边栏（SessionRail）：槽位不再显示 provider 颜色条；折叠后槽位改为正方形、icon 居中；折叠态添加会话按钮只保留加号、不显示文字；移除侧边栏最底部的添加会话按钮。
- 会话库（SessionLibrary）：字号层级互换（元信息大字号、标题小字号）。
- 消息列表：所有消息默认单行显示，超出一行的内容折叠不可见；内容超出一行的消息显示展开按钮，点击展开显示完整内容，再次点击恢复单行折叠；内容不超一行的消息不显示展开按钮。

### 非范围

- 不动左上角品牌区与右上角控制区（属「四面板统一标题栏」task）。
- 不改变消息选择、多选、滚动跟随（新消息底部跟随、prepend 补偿）等既有行为；不改 Markdown 渲染本身与消息数据链路。
- 不改变元信息的数据采集口径（轮次、token 含义不变）；不改变侧边栏折叠/展开交互本身、槽位选择/关闭会话行为；不改动会话库的数据与筛选逻辑。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

### 风险与回退

- 风险：「最后一条消息时间」若现有数据链路没有，需穿透 store 层补字段，工作量扩大；目录末级显示在根目录/无目录会话下的兜底；移除底部添加按钮后展开态缺少添加入口（用户原意即如此，折叠态加号承担）；虚拟列表若假定固定行高，展开/折叠可能引起渲染错乱或滚动跳动；单行截断对代码块/表格等 Markdown 结构的视觉破坏（截断行内出现不完整标记属预期，以纯文本截断或 CSS 截断方案在实施时定）。
- 回退：单 commit revert。
