# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

会话面板之前做过两类改动但未补自动化覆盖：一是字号互换（会话标题改小字号、元信息改大字号），会话库与面板两处均只在 CSS 层落地，组件测试难以断言字号值，视觉断言缺失；二是会话消息列表的滚动与重渲染行为未测——选中态保持已有断言，虚拟列表靠测量行高保证滚动正确，但滚动定位与重渲染行为无自动化覆盖。本 task 只补测试，不改实现。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 为会话标题与元信息的字号层级补自动化断言，会话库与面板两处均覆盖。
- 为会话消息列表的滚动定位与重渲染行为补自动化测试，含长列表虚拟滚动下选中态保持的回归覆盖。

### 非范围

- 不修改样式或组件行为；测试驱动发现的实现问题另行立项处理。
- 不引入视觉快照基建。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] AC1：会话标题与元信息的字号层级有自动化断言覆盖，断言组件挂载的类名与 CSS 规则中对应 font-size 声明的映射（而非 jsdom computed style），会话库与面板两处组件均覆盖。
- [ ] AC2：会话消息列表的滚动定位与重渲染行为有自动化测试覆盖，其中包含长列表虚拟滚动场景下选中态保持的回归用例。
- [ ] AC3：全量单元测试通过，且无新增的 React act 警告。

### 有意不测

已判定不写测试的分支与原因。reviewer 不得据此出 blocking finding。无则写「无」。

- 真实浏览器渲染出的像素级字号与视觉效果：本 task 以 CSS 文本断言替代视觉快照，像素级渲染不属于自动化覆盖范围。

### 测试策略

mock 边界、fixture 来源、断言目标。无特殊约定写「按项目默认」。

- 字号断言沿用项目 CSS 文本断言先例：读取样式表文本，断言组件挂载的类名对应规则中的 font-size 声明，覆盖 `src/renderer/components/workspace/` 下 SessionRail（会话库）与 SessionPane（会话面板）两处。
- 滚动与重渲染测试在 `src/renderer/components/workspace/` 既有 SessionPane.test.tsx、SessionRail.test.tsx 的写法基础上扩展；虚拟滚动测量行高的行为参照既有 spike 结论与既有测试写法，长列表 fixture 按既有测试的数据构造方式生成。
- 断言目标为行为：滚动定位结果、重渲染触发与否、虚拟滚动下选中态保持，不断言内部实现细节。
