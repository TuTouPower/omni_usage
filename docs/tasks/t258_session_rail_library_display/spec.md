## 背景

来源：p073（用户提出）。2026-08-07 核实现状：会话面板左侧侧边栏（`SessionRail.tsx`）每个槽位渲染 provider 颜色条（`rail-accent`，按 source 取 `agent_accent` 色）；底部有「+ 添加会话」按钮（仅展开态渲染）；会话库（SessionLibrary）标题字号大于元信息字号。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 侧边栏各 provider 槽位不再显示颜色条。
- 侧边栏折叠后：各 provider 槽位改为正方形、icon 居中；折叠态的添加会话按钮只保留加号、不显示文字。
- 移除侧边栏最底部的添加会话按钮（展开态的「+ 添加会话」）。
- 会话库中字号层级互换：元信息改为大字号，标题改为小字号。

### 非范围

- 不动工作台会话面板（SessionPane）头部的元信息展示——属另一 task。
- 不改变侧边栏折叠/展开交互本身、槽位选择/关闭会话行为。
- 不改动会话库的数据与筛选逻辑。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] AC1：侧边栏槽位不再渲染 provider 颜色条。
- [ ] AC2：侧边栏折叠后槽位为正方形且 icon 居中显示；折叠态添加会话按钮只显示「+」（无文字）。
- [ ] AC3：侧边栏底部不再存在「添加会话」按钮；展开态添加会话的入口仍可用（由折叠态加号或既有其他入口承担，实施时在实施笔记记录最终形态）。
- [ ] AC4：会话库中元信息字号大于标题字号（层级与现状相反）。
- [ ] AC5：现有测试与 e2e 全部通过，无回归。
