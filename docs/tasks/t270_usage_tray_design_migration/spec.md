# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

t269 组件库就绪后，逐窗口迁移。用量面板是主形态（popup/floating 双形态），托盘菜单是毛玻璃浮层的代表，二者同属 globals 蓝体系，迁移风险最低，作为第一个迁移窗口。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 用量面板（`PopupView` 及下属组件，含 popup/floating 双形态、置顶 pin、动态高度）全部样式迁移到 ui 组件库 + 语义 token。
- 托盘菜单（`TrayMenu`）迁移到统一菜单配方（毛玻璃、圆角、hover 语义）。
- 用量条细线 / 胶囊两种形态及设置中的 `barStyle` 选项原样保留；KPI 大数字、状态点、来源标签、卡片菜单、骨架屏等现存形态逐一保留。
- 迁移完成后删除本窗口专属的手写 CSS 类，并确认无残留引用。

### 非范围

- 不改面板功能逻辑、数据流、窗口控制（动态高度、bounds 持久化、置顶）行为。
- 不动设置 / Agent / 会话窗口（后续 task）。
- 不改 web bridge / local-api / web 专属业务逻辑；共享渲染层（App、组件、类名）的变更随动影响 web 属预期，对应 web e2e 必须保持通过。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] 用量面板全部现存功能行为不变：数据刷新、账户切换持久化、popup/floating 形态切换、置顶、动态高度。
- [ ] 用量条细线 / 胶囊两形态均可正常显示且可在设置中切换；风险阶梯配色不变。
- [ ] 托盘菜单弹出、定位、毛玻璃外观、菜单项行为（含危险项）不变。
- [ ] 面板与托盘在明暗主题下渲染正确，组件内无 `dark:` 分支。
- [ ] 本窗口专属手写 CSS 类已删除且无残留引用（grep 可证）。
- [ ] 视觉与迁移前逐屏对照无意外差异，符合 DESIGN.md。[deploy]

### 可测试性声明

逐条说明哪些 AC 不可自动测试及原因；全部可测则写「全部 AC 可自动测试」。

- AC 6：视觉对照属人工验证，agent 无法自证；其余经现有单测/e2e/黑盒验证。

## 上下文区

reviewer 判测试覆盖时核对本区；实施期可补。

### 有意不测

已判定不写测试的分支与原因。reviewer 不得据此出 blocking finding。无则写「无」。

- 像素级视觉回归：靠人工对照迁移前后截图。

### 测试策略

mock 边界、fixture 来源、断言目标。无特殊约定写「按项目默认」。

- 行为回归以现有用量面板测试为准；迁移失效的样式断言按新语义类名改写，逻辑断言不动。
- 托盘现有测试补齐：全部菜单动作、checked 状态与尺寸上报在迁移后均有覆盖。
- 门禁：`pnpm check`、`pnpm build`、`pnpm test`、对应 web e2e 与 electron e2e；涉及托盘/打包形态，加跑 `pnpm test:packaged`。

### 未知契约清单

尚未核实的外部 endpoint、API 形态、数据结构、第三方行为须分类标记；核实后删除标记，改为结论并注明验证方式。无则写「无」。

`UNVERIFIED-BLOCKING`：只有用户或外部环境能核实；核实前 `start` 失败。

`UNVERIFIED-SPIKE`：agent 可在执行期 Step 1 实验核实；未核实前不得进入实现。

裸 `UNVERIFIED` 属歧义格式，门禁失败。

### 风险与回退

- 风险：popup 动态高度与布局结构耦合，迁移引起高度计算回归；托盘透明窗口的毛玻璃在 Tailwind 化后失效。
- 回退：单 commit，revert 即恢复。
