# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

用户反馈会话面板/会话库首次打开仍卡。调查结论：首屏最多 50 个可见会话的摘要链路中，`resolve_session_file` 无 session_id → 文件路径的持久索引，进程内每个新会话的冷定位都是一次整棵会话目录树的递归扫描（`session-locator.ts` 同步 `readdirSync`，深度 4，慢路径还读每个 jsonl 头部解析首行）；本机约 2600 个会话文件、80% 在 WSL 侧走 UNC 路径，目录遍历延迟放大一个量级；WSL 用户名在默认配置下每次 resolve 都重新探测。定位缓存只是进程内 Map，重启即冷，因此每次启动后的首次打开都重复这批扫描。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 为各来源（claude_code / kimi_code / grok / opencode）建立 session_id（含 env 维度）→ 会话文件路径的持久化索引，应用重启后仍可命中。
- 命中索引的定位不再执行整目录递归扫描；索引失效（文件移动、删除、内容变化）时自动回退到现有扫描定位，并更新索引。
- collector 扫描到新会话或会话文件变化时，索引随之更新。
- WSL 用户名探测结果在进程内与跨重启两个层面缓存，不再随每次 resolve 重复探测。

### 非范围

- 不改变会话摘要、消息内容的提取与展示逻辑（摘要读取量问题由另一 task 处理）。
- 不改变 token-stats collector 的扫描范围与写入时机。
- 不做消息内容搜索索引。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] AC1：应用重启后首次打开会话面板，已在索引中的会话定位不再触发全目录递归扫描（测试中可断言：命中索引时定位路径不执行目录树遍历）。
- [ ] AC2：索引中的文件被移动或删除后，对应会话仍能按现状语义完成定位（回退扫描）或正确报告缺失，且索引被修正，后续定位不再重复失效路径。
- [ ] AC3：新出现的会话文件在 collector 扫描后可被正常定位与打开。
- [ ] AC4：同一批会话在一次会话内被反复定位时，不产生重复的全目录扫描与重复的 WSL 用户探测。
- [ ] AC5：会话打开、摘要显示、消息加载的用户可见结果与现状一致，无功能回归；现有测试与 e2e 全部通过。

### 可测试性声明

逐条说明哪些 AC 不可自动测试及原因；全部可测则写「全部 AC 可自动测试」。

- AC1/AC4：通过注入 fs 计数 fake/spy 的集成测试断言定位路径不触发递归 readdir 与重复用户探测。
- AC2/AC3：tmp 目录 fixture 模拟文件移动/删除/新增，断言回退与索引修正。
- AC5：可自动测试。

## 上下文区

reviewer 判测试覆盖时核对本区；实施期可补。

### 有意不测

已判定不写测试的分支与原因。reviewer 不得据此出 blocking finding。无则写「无」。

- 真实 WSL UNC 路径的网络延迟量级：无法在测试环境模拟；以 tmp 目录 fixture + fs 调用计数断言「不发生扫描」代替延迟测量。

### 测试策略

mock 边界、fixture 来源、断言目标。无特殊约定写「按项目默认」。

- 索引读写在 tmp 目录持久化文件/表上进行，验证跨「重启」（重新构造实例）命中。
- fs 边界用计数 fake 断言递归扫描次数。
- 失效回退：移动/删除 fixture 文件后断言回退扫描与索引更新。

### 未知契约清单

尚未核实的外部 endpoint、API 形态、数据结构、第三方行为须分类标记；核实后删除标记，改为结论并注明验证方式。无则写「无」。

`UNVERIFIED-BLOCKING`：只有用户或外部环境能核实；核实前 `start` 失败。

`UNVERIFIED-SPIKE`：agent 可在执行期 Step 1 实验核实；未核实前不得进入实现。

裸 `UNVERIFIED` 属歧义格式，门禁失败。

- collector 扫描结果中是否已持有可用的 session_id → 路径映射可直接落索引：`UNVERIFIED-SPIKE`，执行期读 collector 与 scan-state 实现核实；若无则索引由 locator 扫描结果自建。

### 风险与回退

- 风险：索引与文件系统真实状态漂移（用户在外部移动/删除会话目录）导致定位失败或误命中；持久化格式变更引入兼容问题。
- 回退：单 commit revert；索引文件损坏或格式不识别的处理为整体丢弃重建（等价退回现状扫描行为）。
