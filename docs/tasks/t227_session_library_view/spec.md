# Task spec

契约区执行期原则上不再改动；确需调整须经用户确认（渲染 review prompt 时脚本会附契约区相对 diff_anchor 的 drift diff 供 reviewer 核对）。上下文区执行期可补。

## 背景

会话窗口外壳的「会话库」页签目前是空态占位。用户确认会话库对齐 demo：搜索/筛选/排序/卡片与列表视图/预览抽屉/多选批量打开；跳过 demo 的次级标签筛选（含错误/含代码/长会话）与导入区；搜索默认只匹配元信息，提供手动「包含消息内容」开关，并提供时间范围选项——只要会话活动时间与所选范围有交集即纳入搜索范围。数据源是真实会话（token-stats 会话索引），不是 demo 的 mock。

## 契约区

reviewer 判 AC 时只看本区。

### 范围

- 会话库页头：标题 + 统计行（会话数 · agent 数 · 总 tokens）。
- sticky 筛选工具栏：搜索框；agent 筛选芯片组（「全部」+ 各 agent，色点 + 名称 + 计数，多选）；排序下拉（最近活跃 / Token 最多 / 轮次最多 / 最早创建）；网格/列表视图切换。
- 搜索选项：默认只匹配元信息（标题/cwd/文件路径）；「包含消息内容」开关开启后连消息正文一起搜；时间范围选项（起止日期），只纳入活动时间与范围有交集的会话。
- 结果区：网格视图为会话卡片（agent 色条、徽标、标题、首条用户消息摘要、mono meta 行 `轮数 · tokens · 相对日期`、cwd/路径）；列表视图为行式；hover 浮现「单独打开 / 预览」；点卡片/行 = 勾选（上限 8，超限提示）。
- 分页加载：「加载更多」逐步加载，避免一次性渲染全部会话。
- 预览抽屉：右侧滑出，显示徽标、标题、meta、文件路径、前 5 条消息（只读简化渲染），底部「单独打开 / 加入选择」；Esc 关闭。
- SelectionDock：底部 sticky，已选会话微缩槽位（可移除）、`n/8` 计数、清空、「并排打开 (n)」——把选中会话依次写入工作台槽位并切到工作台页签。
- 空结果态：无匹配时显示引导（清除筛选）。

### 非范围

- 不做次级标签筛选（含错误/含代码/长会话）。
- 不做拖文件导入区。
- 不做 demo 的营销首页。
- 不改工作台槽位/pane/摘选托盘本身（仅消费其 store 完成批量打开）。

### 验收标准

只写用户或调用方可观察行为，每条可独立验证。普通版本号、底层库和目录结构不作为验收标准；需要长期约束后续工作的技术选择写入 `docs/blueprint/decisions.md`。

需真实部署或人工环境才能验证的条目加 `[deploy]` 前缀，标明 agent 无法自证。

- [ ] 会话库页头显示统计行：`N 个会话 · M 个 Agent · X tokens`，与当前筛选前的全量数据一致。
- [ ] 搜索框默认只匹配标题/cwd/文件路径；开启「包含消息内容」后，正文含关键词的会话也出现在结果中。
- [ ] 设置时间范围（起止日期）后，只有活动时间与该范围有交集的会话纳入搜索与结果。
- [ ] agent 芯片可多选过滤（带每 agent 计数）；排序下拉四种排序生效；网格/列表视图切换生效。
- [ ] 会话卡片显示 agent 色条、徽标、标题、首条用户消息摘要、`轮数 · tokens · 相对日期`、cwd/路径；列表视图显示等价信息。
- [ ] 点卡片/行勾选会话（上限 8，第 9 个提示拒绝）；hover 浮现「单独打开 / 预览」。
- [ ] 预览抽屉显示标题、meta、文件路径与前 5 条消息；「单独打开」把该会话装入工作台槽位并切到工作台；「加入选择」勾选该会话；Esc 关闭抽屉。
- [ ] SelectionDock 显示已选会话微缩槽位（可单个移除）、`n/8` 计数、清空；「并排打开 (n)」把选中会话写入工作台槽位并切到工作台页签。
- [ ] 「加载更多」分页加载会话；无匹配结果时显示含「清除筛选」的空态。
- [ ] 工作台槽位已满时从会话库「单独打开/并排打开」，遵守超位提示规则（toast 拒绝，不替换已有槽位）。

### 可测试性声明

逐条说明哪些 AC 不可自动测试及原因；全部可测则写「全部 AC 可自动测试」。

- AC 2「包含消息内容」的真实性能（对候选会话逐个跑提取器）：以受控 fixture 测正确性；大数据量下的响应表现标 `[deploy]` 黑盒验证。
- 其余 AC 均可自动测试（组件测试 + mock 数据层）。

## 上下文区

reviewer 判测试覆盖时核对本区；实施期可补。

### 有意不测

已判定不写测试的分支与原因。reviewer 不得据此出 blocking finding。无则写「无」。

- 逐字动画标题等装饰动效：无行为断言价值。

### 测试策略

mock 边界、fixture 来源、断言目标。无特殊约定写「按项目默认」。

- 筛选/排序/搜索/时间范围：数据层纯函数测试 + 组件测试，fixture 仿照 token-stats 会话结构。
- 批量打开：组件测试断言写入工作台槽位 store 与页签切换。
- 预览抽屉前 5 条消息：mock sessionHistory query 返回。

### 未知契约清单

尚未核实的外部 endpoint、API 形态、数据结构、第三方行为须分类标记；核实后删除标记，改为结论并注明验证方式。无则写「无」。

`UNVERIFIED-BLOCKING`：只有用户或外部环境能核实；核实前 `start` 失败。

`UNVERIFIED-SPIKE`：agent 可在执行期 Step 1 实验核实；未核实前不得进入实现。

裸 `UNVERIFIED` 属歧义格式，门禁失败。

- 会话索引数据源（tokenStatsStore.query_sessions 桥接）能否支撑全量会话列表、分页、按时间范围/排序的查询，以及统计行所需字段：`UNVERIFIED-SPIKE`，执行期读 main 侧 store 与桥接代码核实；能力不足时需设计查询扩展方案并报用户确认。
- 「包含消息内容」搜索在真实数据量下的耗时量级：`UNVERIFIED-SPIKE`，执行期用真实或仿真的会话文件做小规模实验核实，决定是否需加进度提示/并发上限。

### 风险与回退

- 风险：全量会话列表与内容搜索性能不达标；会话索引缺少会话库所需字段（首条用户消息摘要、相对日期、token 总数）需扩查询。
- 回退：单 commit revert；性能不达标时降级为仅元信息搜索并保留开关置灰说明，报用户确认。

### 依赖与约束

- 依赖摘选系统与工作台槽位模型已落地（见 task.md front matter 依赖链）。
- 内容搜索只读源文件，沿用提取器只读约束；不对源文件做任何写入。
